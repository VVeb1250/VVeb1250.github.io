## A debugging episode

Recall quality dropped badly. The suspect was a 25-row cap — it was not the cause. Values written by the producer ran about 221 characters, against about 106 for ones people wrote, so only about five rows fit in the recall budget.

Since then, a rule that matters gets a hook or a gate, not only prompt text.

## What turned out wrong

- A token / compression advantage, as first assumed.
- Path or symbol proximity as relevance.
- That existing systems cannot carry context across sessions.
