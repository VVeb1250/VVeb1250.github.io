## Install

Installs into the project, not into global settings, for Codex, Claude Code and VS Code agents.

<CopyText text="npx whipui init" />

## Where it stands

It started as help for following a design brief and grew toward a fuller design harness. Newer models handle more on their own, so some layers may no longer be needed.
