## デバッグの一件

想起の品質が大きく低下しました。当初は25行の上限が原因かと考えましたが、違いました。producer が書いた値は約221文字で、人が書いた値は約106文字でした。そのため、想起の予算に収まるのは約5行だけでした。

それ以降、重要なルールはプロンプトの文章だけでなく、hook や gate で担保するようにしています。

## 想定と違っていたこと

- token・圧縮の利点（当初想定していたもの）
- path や symbol の近さを関連性の指標とすること
- 既存のシステムではセッションをまたいで文脈を引き継げないこと
