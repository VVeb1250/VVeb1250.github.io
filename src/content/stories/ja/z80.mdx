## ブラウザで動く本物のツールチェーン

授業で使われる assembler と simulator を、WebAssembly にコンパイルした DOSBox で動かしています。

<FlowDiagram n="01" caption={{ en: 'Toolchain', ja: 'ツールチェーン' }} nodes={[
  { id: 'ed', col: 0, label: 'Monaco editor', sub: '.ASM' },
  { id: 'as', col: 1, label: 'C16.EXE', sub: 'DOSBOX → WASM', core: true },
  { id: 'hx', col: 2, label: 'Intel HEX', sub: '+ LISTING' },
  { id: 'sim', col: 3, label: 'Z80sim', sub: 'ET-BOARD SIMULATOR' }
]} edges={[
  { from: 'ed', to: 'as', active: true },
  { from: 'as', to: 'hx', active: true },
  { from: 'hx', to: 'sim', active: true, label: { en: 'loads on its own', ja: '自動で読み込み' } }
]} />

複数ファイルのワークスペースをブラウザ内に保持し、Intel HEX とリスティングに組み立てます。コンパイル済みのファイルは自動的に Z80sim に読み込まれ、各ファイルのビルド状態は3色のいずれかで表示されます。TH / EN の切り替えと、UI のツアーがあります。

デスクトップ版として Electron ビルドも用意しており、私自身も使っています。
