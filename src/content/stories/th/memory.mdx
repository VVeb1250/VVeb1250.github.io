## เหตุการณ์ที่ต้องแก้

คุณภาพของการ recall ลดลงอย่างมาก ตอนแรกสงสัยว่า cap 25 แถวเป็นสาเหตุ แต่ผลการตรวจสอบพบว่าไม่ใช่ ค่าที่ producer เขียนยาวราว 221 ตัวอักษร ส่วนที่คนเขียนยาวราว 106 ตัวอักษร ทำให้ใส่ได้แค่ราว 5 แถวใน budget ของการ recall

หลังจากนั้น ผมกำหนดให้กฎที่สำคัญมี hook หรือ gate กำกับ ไม่ได้พึ่งเพียงข้อความใน prompt

## สิ่งที่ผิด

- ข้อได้เปรียบด้าน token และการบีบอัด ตามที่คาดไว้ตอนแรก
- การใช้ความใกล้กันของ path หรือ symbol เป็นตัววัดความเกี่ยวข้อง
- ระบบที่มีอยู่ในปัจจุบันยังส่งต่อบริบทข้าม session ไม่ได้
